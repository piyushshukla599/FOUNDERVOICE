# Release Notes — FounderVoice AI v1.0.0

**Ship date:** 2026-07-31  
**Positioning:** 100% free · local-first · privacy-first executive speech coach

## Headline

FounderVoice doesn’t just score your pitch. It remembers how you speak and tells you **why** something happened and **how** to fix it — with timestamped evidence.

## What’s in 1.0

- Record, Smart Session, Library, Dashboard, Coach, Labs, Practice
- Local Whisper + professional voice report + Voice Memory
- Works fully without a cloud AI key (elite local templates)
- Optional cloud coaching text if you add your own API key server-side
- Feedback & contact form; Privacy & Terms; Docker API; launch docs

## What we deliberately don’t do

- No cloud audio vault
- No forced accounts for local use
- No accent-change claims
- No paywall on core coaching

## Try it

1. Start API + web (see README)
2. Open `/welcome` then **Start recording**
3. Read session findings; click transcript timestamps

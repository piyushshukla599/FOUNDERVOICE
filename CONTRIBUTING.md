# Contributing

Thanks for helping FounderVoice stay local-first, private, and free.

## Principles (do not break)

- Audio stays on the user’s machine
- No cloud audio storage
- Coaching quality bar: observation → cause → fix (+ exercise)
- Prefer vertical slices over orphan metrics
- Do not invent product features in docs — verify in code

## Setup

See [README.md](./README.md) and [docs/02-SETUP.md](./docs/02-SETUP.md).

## Pull requests

1. Keep changes focused.
2. Update `docs/` when behavior changes.
3. Do not commit `.env`, API keys, or `data/` user media.
4. Prefer small PRs with a clear “why”.

## Code style

- Match existing TypeScript / Python patterns in the repo.
- Avoid drive-by refactors unrelated to the PR.
